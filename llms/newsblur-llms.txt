# NewsBlur

> NewsBlur is a personal news reader (RSS/Atom aggregator) with training-based intelligence, saved stories, folders, OPML import/export, and a social "blurblog" layer. It is open source (MIT) and exposes a documented HTTP API plus an official hosted Model Context Protocol (MCP) server for AI agents.

This llms.txt was generated by API Evangelist from the public NewsBlur API reference and the open-source repository; NewsBlur does not publish its own llms.txt (probed 2026-07-20, 404).

## APIs
- [NewsBlur API reference](https://www.newsblur.com/api): Full documented endpoint list (auth, feeds, stories, social, classifiers, OPML).
