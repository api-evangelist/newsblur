The reason Joplin’s Web Clipper is useless for this is because the URL NewsBlur is showing doesn’t reference the article being shown. The NewsBlur team could fix this by updating the URL as articles are being viewed, e.g. change: https://www.newsblur.com/site/: / to something like this (for a link back to a specific article in NewsBlur): https://www.newsblur.com/site/: / / …or even better, include a link to the target article, as a favor to other developers: https://www.newsblur.com/site/: / / # Then Joplin Web Clipper’s “Clip URL” would work as expected.
