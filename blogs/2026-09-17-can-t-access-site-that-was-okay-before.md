That message is coming from Bored Panda’s own site, not from NewsBlur. You have that feed set to Story view, which loads the actual boredpanda.com page inside NewsBlur, and their site is crashing when it loads that way. Switch the view for that feed to Feed or Text using the view buttons at the top of the story list and the stories will read normally.
